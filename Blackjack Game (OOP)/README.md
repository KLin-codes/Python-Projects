## 1. Blackjack (OOP Console Game)

A command-line Blackjack game implemented in Python. For learning and practicing purpose only.

**Features:**
- Object-Oriented Programming (OOP) design
- Multiple decks using a shoe system
- Dealer and player logic
- Ace handling (1 or 11)
- Hit / Stand gameplay
- Basic game flow and rules implementation

**Purpose:**
This project was created to practice:
- Python OOP principles (classes and objects)
- Function decomposition
- Handling edge cases (e.g. multiple Aces)
- Structuring a small interactive program

**Future Improvements:**
- Add betting system (chips, bankroll tracking)
- Implement splitting and doubling down rules
- Improve dealer AI and game logic edge cases
- Improve user experience (clearer UI/UX and formatting)
